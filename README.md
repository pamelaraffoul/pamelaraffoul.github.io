# Pamela Raffoul – Portfolio

Personal portfolio website of **Pamela Raffoul**, Techno-Functional Salesforce Consultant.

🌐 **Live site:** [pamelaraffoul.github.io](https://pamelaraffoul.github.io)
💼 **LinkedIn:** [linkedin.com/in/pamela-raffoul2002](https://www.linkedin.com/in/pamela-raffoul2002)

## Features

- Responsive layout for desktop, tablet and mobile
- Dark theme with a teal and violet palette
- **Pixel**, a scripted chatbot that answers common questions about my profile
- Downloadable CV, back-to-top button and scroll animations
- Accessible: semantic HTML, keyboard navigation, screen-reader labels and reduced-motion support
- Link previews for LinkedIn and messaging apps (Open Graph)

## Built with

Plain **HTML5**, **CSS3** and **JavaScript**, with no frameworks or build step. Hosted for free on **GitHub Pages**.

## Project structure

```
├── index.html            Page content and structure
├── style.css             Styles, organized by section
├── script.js             Menu, animations, back-to-top and chatbot
├── Pamela-Raffoul-CV.pdf Downloadable CV
├── favicon.png           Browser tab icon
├── apple-touch-icon.png  Home-screen icon on phones
└── og-image.png          Preview image when the link is shared
```

## Run locally

Clone the repository and open `index.html` in any browser.
